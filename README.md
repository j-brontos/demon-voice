# Demon Voice

Experimentální webová aplikace pro živou změnu hlasu na iPhonu. Používá Web Audio API, mikrofon a zvukový výstup vybraný v iOS.

## Spuštění

Zapni GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). Potom otevři https://j-brontos.github.io/demon-voice/ v Safari. Povol mikrofon a stiskni Spustit mikrofon.

## Omezení

Při použití Bluetooth může být zvuk opožděný. iOS může přesměrovat zvukový výstup po aktivaci mikrofonu. Funkčnost s konkrétním reproduktorem zatím nebyla ověřena. Nejde o nativní iOS aplikaci a při uzamčení obrazovky může přestat fungovat. Použitý pitch-shift algoritmus je experimentální.
